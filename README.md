# NX-Project-Manager

### Command
`nx-cli <option> <flags>`

### Subcommands & Options
**new** `nx-cli new -e <empty> -l <lang> -n <name>`

| Options    | Type | Values      | Necessary |
|:------------:|:------:|:-------------:|:-----------:|
| `-e/--empty` | bool | `true, false` | No        |
| `-l/--lang`  | &str | `c, cpp, cxx` | No        |
| `-n/--name`  | &str | `<name>`      | Yes       |
